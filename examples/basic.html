html2gui

WHATWG HTML + Lexbor CSS selectors + SDL3

Our first native C89 GUI frame

The document is parsed with Lexbor. Styles are matched by CSS selectors. Text and boxes are laid out into a retained display list and drawn by SDL3.

Try clicking the buttons or editing the text field. Arrow keys, Home, End, Backspace, Delete and Tab work. Escape blurs the field; press Escape again to close the window.

Next: real CSS layout

This initial slice handles basic blocks, equal-width flex rows, color, spacing, text, and dimensions. Grid, inline formatting, backgrounds beyond solid colors and most modern CSS are not implemented.
